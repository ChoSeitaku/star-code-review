# vuln-demo —— 示例评估目标项目

> **警告：本项目中的代码包含故意植入的安全缺陷，仅用于演示自动化安全评估系统的
> 接入、分析、验证与报告全链路。请勿部署、勿用于生产环境、勿复制其中的写法。**

## 用途

这是「自动化安全评估系统」的默认演示目标。项目模拟了一个典型的中小型 Web 业务
服务，覆盖了最常见的几类源码安全缺陷，便于在演示中直观看到系统如何发现问题、
验证问题并串成攻击路径。

## 缺陷清单

| 文件 | 缺陷类型 | 说明 |
| --- | --- | --- |
| `config.py` | 硬编码敏感凭据 | 数据库口令、第三方 API Key 以明文常量写入源码 |
| `config.py` | 生产环境开启调试模式 | `app.run(debug=True)`，异常时向客户端暴露堆栈 |
| `db.py` | SQL 注入 | 查询条件由字符串拼接构造，未使用参数化查询 |
| `db.py` | 弱哈希算法 | 使用 MD5 加盐前的快速哈希保存用户口令 |
| `db.py` | 口令明文存储 | 用户注册时直接把明文口令写入存储结构 |
| `app.py` | 命令注入 | 网络诊断接口把用户输入拼接进系统命令 |
| `app.py` | 跨站脚本（XSS） | 欢迎页把用户名直接渲染进 HTML，未做实体转义 |
| `app.py` | 路径遍历 | 文件下载接口用用户输入拼接路径，未校验目录边界 |
| `app.py` | 动态代码执行 | 计算器接口使用 `eval` 执行用户表达式 |
| `app.py` | 服务端请求伪造（SSRF） | 链接预览接口可被诱导请求内网地址 |
| `app.py` | 不安全的反序列化 | 会话恢复接口直接 `pickle.loads` 外部数据 |
| `app.py` | 异常处理吞掉错误 | 多处 `except: pass`，安全事件不留痕 |

## 在系统中使用

1. 启动后端服务后，在「项目创建页」填写：
   - **源码类型**：本地源码目录
   - **源码路径**：`examples/vuln-demo`
   - **任务说明**：对示例业务服务进行源码安全评估
2. 启动评估任务，在实时监控页观察阶段推进与角色执行。
3. 评估完成后查看漏洞列表、攻击路径与最终报告。

也可以直接运行无头演示脚本，一键跑完整条链路：

```bash
.venv/Scripts/python.exe demo/run_demo.py
```

## 关于隔离

评估系统会以**只读**方式挂载本目录，所有分析在隔离环境内完成。
示例代码中的危险调用仅被静态识别与"拼接复现"，不会真正执行。
